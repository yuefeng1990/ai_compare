### 3. **授权按钮选择器列表**

已添加多种可能的选择器：

```python
login_button_selectors = [
    'button:has-text("授权")',           # 主要选择器
    'button:has-text("用户登录-授权")',
    'button:has-text("登录")',
    'button:has-text("确认")',
    'button:has-text("同意")',

    'a:has-text("授权")'                 # a链接

```

### 4. **智能Fallback机制**

如果所有预设选择器都失败：
1. 查找页面上所有可点击元素（button, a, div等）
2. 显示每个元素的文本和class信息
3. 自动尝试点击包含"授权"、"登录"、"Login"或"Authorize"文本的第一个元素

## 🐛 常见问题

### 问题1：找不到授权按钮

**症状**：提示"未找到授权按钮"或"无法找到授权按钮"

**解决**：
1. 运行 `python debug_auth_page.py` 获取准确的元素信息
2. 确认是否在正确的页面上（授权页面，不是首页）
3. 检查授权按钮是否使用了iframe
4. 根据调试输出更新选择器列表

### 问题2：点击授权后没有反应

**症状**：点击了按钮但页面没有跳转

**可能原因**：
1. 用户名或密码输入错误
2. 需要先勾选"同意条款"复选框
3. 按钮被禁用（disabled属性）
4. JavaScript错误

**解决**：
1. 检查输入的用户名和密码是否正确
2. 查看页面上是否有需要勾选的复选框
3. 检查浏览器控制台是否有错误信息
4. 增加点击后的等待时间

### 问题3：登录后卡在首页

**症状**：授权成功但后续操作失败

**解决**：
1. 检查登录成功检测的选择器是否正确
2. 增加等待首页加载的时间
3. 确认首页的菜单结构是否符合预期

## 💡 最佳实践

1. **优先使用ID选择器**：最稳定，不易受样式变化影响
2. **结合文本和类名**：提高选择的准确性
3. **添加详细日志**：便于调试和问题定位
4. **设置合理的超时**：不要太短（容易失败）也不要太长（浪费时间）
5. **准备多重fallback**：多种选择器策略提高成功率
