```python
def automate_browser(web_checker):
    # 1. 检查登录状态
    if not is_logged_in:
        # 2. ⭐ 先点击"立即登录"按钮
        immediate_login_selectors = [...]
        for selector in immediate_login_selectors:
            element = web_checker.page.query_selector(selector)
            if element:
                web_checker.page.click(selector, timeout=5000)
                time.sleep(2)  # 等待页面跳转
                break
        
        # 3. 然后输入用户名和密码
        manual_login(web_checker)
```

## 🎯 核心特性

### 1. **两步登录** ✅
严格按照您要求的顺序：
1. 先点击"立即登录"
2. 再输入用户名密码

### 2. **智能选择器** ✅
每个操作都尝试多种选择器，提高成功率：
- "立即登录"按钮：7种选择器
- 用户名输入框：7种选择器
- 密码输入框：4种选择器
- 登录按钮：8种选择器

### 3. **等待机制** ✅
- 点击"立即登录"后等待2秒（页面跳转）
- 登录成功后等待菜单出现（最多15秒）

### 4. **详细日志** ✅
每一步都有清晰的输出，方便调试：
