## 🔧 技术实现细节

### 关键字映射机制

系统采用**多对一映射**策略，一个英文关键字可以对应多个中文标签：

```python
'Manufacture': ['企业简称（英文）', '企业简称', '英文简称', 'Manufacturer']
```

**优势：**
- ✅ 提高匹配成功率
- ✅ 兼容不同的页面文案
- ✅ 支持国际化场景

### 提取流程

```
输入：英文关键字 (Manufacture)
  ↓
步骤1：查找中文标签映射
  → ['企业简称（英文）', '企业简称', '英文简称', 'Manufacturer']
  ↓
步骤2：尝试HTML结构提取
  → 查找 <label>企业简称（英文）：</label>
  → 如果找到，提取后续 <text> 或 <span> 中的值
  ↓
步骤3：尝试表格格式提取
  → 在垂直表头中查找"企业简称（英文）"
  → 如果找到，映射到对应的列索引
  → 从数据行提取该列的值
  ↓
步骤4：回退到文本行匹配
  → 在纯文本中查找包含标签的行
  → 提取冒号后的值
  ↓
输出：提取到的值 或 None
```
